# SolarTech Landing Page

A premium solar energy landing page created with semantic HTML5 and CSS3 only.

## Project structure

- `index.html` – page structure and content
- `css/style.css` – full styling, layout, responsiveness, and hover effects
- `images/` – solar-themed photography assets used throughout the page

## How to view locally

Open `index.html` directly in a browser, or serve the folder with a simple local server:

```bash
cd solar-landing-page
python -m http.server 8000
```

Then visit `http://localhost:8000`.
